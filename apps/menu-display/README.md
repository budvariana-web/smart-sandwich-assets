# Smart Sandwich Bar — меню на экран

Рабочий проект для горизонтального 47-дюймового экрана (ориентир — 1920×1080). Сотрудник управляет меню в Google Таблице, экран читает его через привязанный к таблице Google Apps Script и обновляется каждые 60 секунд.

## Что уже реализовано

- адаптивная горизонтальная сетка: до 12 текстовых позиций либо до 8 карточек с фотографиями на одном кадре;
- автоматическое перелистывание, когда позиций больше вместимости;
- автоматическое обновление данных;
- при пропадании сети — показ последней загруженной версии из памяти браузера;
- «нет в наличии» скрывает блюдо;
- обработка русских и английских заголовков столбцов;
- настройки бренда и интервалов через опциональный лист `SETTINGS`.

## Формат листа MENU

Первая строка — заголовки. Обязательны только `Название` и `Цена`.

| Категория | Название | Описание | Цена | Старая цена | В наличии | Порядок | Фото | Бейдж |
|---|---|---|---|---|---|---:|---|---|
| Бургеры | Чизбургер | Говядина, сыр, соус | 490 |  | Да | 10 | https://… | Хит |
| Сэндвичи | Индейка BBQ | Индейка, салат, BBQ | 420 | 470 | Да | 20 | https://… | −10% |
| Напитки | Лимонад | Домашний, 0.4 л | 250 |  | Нет | 10 |  | |

Пустое поле `В наличии` трактуется как «Да». Значения `Нет`, `false`, `0`, `нет в наличии` скрывают строку. `Порядок` управляет сортировкой внутри категории.

## Настройки (опционально)

Создайте лист `SETTINGS` с двумя столбцами:

| Параметр | Значение |
|---|---|
| Бренд | SMART SANDWICH BAR |
| Обновление сек | 60 |
| Перелистывание сек | 15 |

## Публикация — один раз

1. Откройте исходную таблицу → **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` кодом из этого проекта.
3. Создайте HTML-файл `Index` и вставьте `Index.html`.
4. В настройках проекта задайте манифест `appsscript.json` (необязательно, но задаёт часовой пояс).
5. Нажмите **Развернуть → Новое развертывание → Веб-приложение**.
6. Выполнять от имени: **Я**. Доступ: **Все** — телевизор не потребует входа в Google.
7. Скопируйте URL, оканчивающийся на `/exec`, и откройте его на экране.

## Режим на экране

- **Android TV / Android-приставка:** Chrome или Fully Kiosk Browser, URL `/exec`, полноэкранный режим, автозапуск после включения.
- **Мини‑ПК / Windows:** Chrome с параметром `--kiosk "URL_МЕНЮ"`.
- Отключите заставку и автоотключение дисплея.

## Текущий статус публикации

- Google Sheets API и Google Apps Script API включены.
- Таблица подготовлена: листы `MENU` и `SETTINGS`; в `MENU` загружены тестовые позиции.
- Web App опубликован для анонимного просмотра на экране. Рабочая ссылка и технические ID сохранены в `deployment.json` и `HANDOFF.md`.

> Секретный ключ сервисного аккаунта, OAuth client и OAuth-токены не используются экраном и не должны добавляться в Apps Script, архив проекта или чат. Они нужны только для отдельных административных операций и выдаются владельцем по защищённому каналу.
